# Web party weapon

`p_ak47.mdl` is the stock Counter-Strike 1.6 player-held AK-47 model from the local `cstrike/models` installation. Vite bundles it as a web asset for the party scene in development and production. The web party scene loads each member's selected weapon skin model from the server when available. This bundled model is the fallback when no selected model can be loaded.
